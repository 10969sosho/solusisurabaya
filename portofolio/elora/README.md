# ÉLORA

Frontend-only premium beauty brand demo for presentation. Open `index.html` directly in a browser or serve this folder with any static file server.

## Pages

- `index.html` — cinematic home experience
- `shop.html` — eight-product catalog with filters, sorting, and add-to-bag actions
- `product.html` — Renewal Serum detail and scroll-led product story
- `about.html` — brand story and philosophy
- `journal.html` — editorial archive
- `cart.html` — persistent demo bag and checkout state

The demo uses Google Fonts and Unsplash images via CDN, plus GSAP and ScrollTrigger via jsDelivr. No build step, backend, database, API, Laravel, React, or framework is required.
